# 项目文件夹架构检查

检查日期：2026-10-27。范围：本地目录、运行与构建关系、资源清单、文档导航和仓库边界。

结论：现有分区能够支撑当前静态游戏，正式构建源、生成文件和采用资源一致。主要维护成本来自历史命名、缺少总索引，以及当前材料与历史材料并置；本轮仅检查与记录，未移动文件或调整运行代码。

## 当前目录职责

```text
cjb/
├─ index.html、styles.css             游戏页面与样式
├─ engine.js、game.js                 引擎与界面交互
├─ save-compat.js、player-runtime.js  存档与播放适配
├─ story.js                          正式剧情生成物
├─ assets/                           运行图、采用清单、原件、候选与美术画廊
├─ 任务拆分/
│  ├─ 三章扩展/                     约定构建入口及旧三章源
│  └─ 全十章/
│     ├─ common/、routes/             10份共通模块与7份路线模块
│     ├─ presentation/                演出绑定源与准备器
│     ├─ build/                       构建程序
│     ├─ 构建/                        隔离样例产物
│     └─ 校验/、交接/                 阶段证据与说明
├─ 项目文档/                         人物、故事、分支与资源规范
├─ qa/                               检查脚本、输入、报告、截图与基线
├─ deployment/                       各平台发布源、配置及历史证据
├─ 交付/全十章-E11/                  打包程序、模板及本地交付副本
├─ 毕节场景参考/、贵阳场景参考/      实拍参考原件
└─ scripts/                          通用美术转换工具
```

根目录游戏无需安装依赖；部署工具和浏览器检查另有依赖。正式构建关系为：

`全十章审阅稿／契约 → common＋routes＋presentation → 三章扩展/build-story.cjs → 全十章/build/formal.cjs → story.js、运行清单、来源映射、构建报告 → 游戏与发布包`。

当前运行的是网吧夜班版全十章；`项目文档/故事/v1.1润色稿/` 是尚未接入游戏的独立文稿。两者不可按文件日期混用。

## 体积与保留范围

本地磁盘占用约5.3G（`du -sh`口径），其中 `.git` 约1.6G、`deployment/` 约1.5G、`assets/` 约1.2G、`qa/` 约580M、`交付/` 约353M、`任务拆分/` 约46M。目录占用包含依赖、快照及重复副本，不能等同于线上包体积；当前发布白名单为146文件、182,160,244字节。

美术及参考图存在87组逐字节相同的图片，重复副本约140MB；多数具有采用图、制作原件或来源副本等不同职责。E11的ZIP与解压副本也属于明确保留的交付材料，其 `dist/` 已被忽略。按[美术规范](美术资源规范.md)，不因目录整理删除原件、转换历史截图或覆盖发布快照。
