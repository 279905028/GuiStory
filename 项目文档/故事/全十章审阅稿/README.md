## 分支怎么读

先看[十章故事流程图](../../分支/游戏流程图.md)，可定位章节日序、七线结局、隐藏条件及选择回收。

1. 第一、二章读共通故事；遇到选项，只读所选项，随后回到共同段。这些选择影响后文回应，不提前锁定恋爱路线。
2. 第三章选小满、周栀、孟遥、叶岚、飘、朋友与职业或黄球球中的一条。第三至第十章均先读共通正文，再读同一条路线；其他路线的私人经历不视为已经发生。
3. 第四章每条路线有一组日常选择，第七章读取相应回收段。人物会记住一起做过的事，但没有数值好感度。
4. 小满、周栀、孟遥、叶岚、黄球球在第九章选择交往或朋友；第十章只读对应结局。朋友与职业线独立完结。
5. 飘在第三章第21天就选择交往或朋友，此后各章保持这个结果。与文文交往时，两年后仍是恋人；其余合法路径承接飘与毛狼的婚姻。
6. 黄球球需满足“第1天记录三拍＋第8天敲回节奏”，在第14天网吧后院侧门正式相识后，才可在第三章选她。她是成年女性，前期保持球形；第七章铺垫，第八章第55天自主变为[用户照片参考的人形](../../人物/黄球球.md#已确认外形与资源)，恋人／朋友结局均延续人形。不通过手机联系，也不向普通路线的人物显露。
7. 第六章的孟遥、叶岚个人段补叙第30天同一顿饭后的相处，再接后续日期。第十章先读适用的飘关系后日谈，再读所选路线的结局；两年后的各场不要求发生在同一天。

## 本稿的主线安排

文文从22:00—06:00夜班、补觉、房租与朋友邀约开始生活。他会玩得开心，也会答应太快、错过约局、把熟悉误当成了解；相处由各条路线自己的经历推进。

第30天保留回声的最后营业夜，作为周栀生活的变化。朋友们傍晚吃饭，周栀和文文随后各自上班。第52天文文与师匠、同事商量试排，第61天确认轮班，两年后仍在网吧工作。原稿的拍片、同岗竞聘与活动执行主线已替换。
