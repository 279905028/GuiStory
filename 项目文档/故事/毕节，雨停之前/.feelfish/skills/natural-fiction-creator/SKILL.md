# 自然小说创作引擎

本技能旨在帮助创作者写出有烟火气、有人味、没有 AI 痕迹的小说。融合两代工具箱精华，新增配角活性化专项模块和章节重复检测机制，每一次写作都是一次提升。

## 核心架构

```
【用户输入】→ 题目+方向+大概
       ↓
【指令理解器】→ 解析类型、风格、核心设定
       ↓
┌─────────────────────────────────────────┐
│              创作引擎核心                │
├─────────────┬───────────────┬───────────┤
│ 世界观构建器 │  人物生成器    │ 情节规划器 │
├─────────────┼───────────────┼───────────┤
│ 章节生成器   │  诊断优化器    │ 复盘优化器 │
├─────────────┴───────────────┴───────────┤
│         章节重复检测模块（新增）          │
└─────────────────────────────────────────┘
       ↓              ↓              ↓
【核心判断层】←→【经验池】←→【优化机制】
```

**核心判断层**：所有创作心法、分寸感、判断力的集合。
**经验池**：存储成功案例、失败教训、用户偏好、已用表达库。
**优化机制**：每章复盘，提炼心法，存入经验池，供后续章节参考。

## 工作流程

### 1. 指令理解
- 解析用户提供的「题目」、「方向」、「大概」
- 识别小说类型（网文、严肃文学等）、风格（幽默、黑暗等）、核心设定
- 确定本章在整体情节中的位置（开篇、发展、高潮、尾声）

### 2. 创作引擎核心
根据解析结果，协同调用以下模块：

#### 世界观构建器
- 确保场景细节符合世界观设定
- 注入烟火气细节：有人在收衣服、有人在逗虫子、食堂大妈偷吃红烧肉等

#### 人物生成器
- 确保主角行为符合性格和处境动机
- **重点应用配角活性化模块**（见专项部分）
- 为每个配角赋予「三秒人生」

#### 情节规划器
- 基于 17 项核心判断力规划本章节奏
- 确定信息密度分布：日常章碎片化，关键章集中化
- 设计符合「同步发现力」的情节推进

#### 章节生成器
- 按照输出规范生成正文
- 应用「一句话心法」指导具体写作
- 确保自然度，避免 AI 痕迹
- **创作时自动规避与之前章节的重复表达**

#### 诊断优化器
- 生成后自动运行「章节生成自动检测清单」
- 检查基础规范、衔接逻辑、配角活性化、自然度等
- **运行章节重复检测**（见专项模块）

#### 复盘优化器
- 分析本章成功与不足
- 提炼心法，丰富经验池
- 为下一章创作提供优化指导
- **记录本章独特表达，避免后续章节重复**

### 3. 核心判断力应用（17 项通用版）

创作过程中必须时刻应用以下 17 项判断力：

| 序号 | 判断力 | 核心说明 | 应用要点 |
|------|--------|----------|----------|
| 1 | 节奏判断力 | 能判断这一章需要紧张还是舒缓 | 冲突章后接日常章，连续紧张会累，连续日常会腻 |
| 2 | 信息密度判断力 | 能判断什么时候该碎、什么时候该整 | 日常章碎片化，关键章集中化但不靠对话科普 |
| 3 | 细节感知力 | 能感受这一章缺不缺温度 | 干则加细节，腻则删。细节离"人的感受"近的写，远的略 |
| 4 | 结尾判断力 | 能判断该收在哪儿 | 冲突章收悬念，日常章收情绪，过渡章收意象 |
| 5 | 角色生命力判断力 | 配角要有独立生活感 | 细化：配角要有独立生活感、意外反应、独立台词、关系网、记忆点。离开主角，他还在活着吗？ |
| 6 | 章法判断力 | 该详则详，该略则略 | 时间可跳，开篇不模板，结尾不固定 |
| 7 | 自然度检测力 | 读起来像人写的吗 | 开篇不"醒来"，结尾不"看窗外"，对话不交代设定，用词不套话，配角不工具人 |
| 8 | 句式优化判断力 | 能识别并避免常见句式问题 | 禁用否定铺垫重复句式，避免结构雷同，开篇结尾不重复，打破"复读机"模式 |
| 9 | 主角行动驱动力 | 每个行动有动机 | 性格/处境/情感的动机，不为剧情需要而行动 |
| 10 | 同步发现力 | 关键信息让读者和主角同时发现 | 不提前剧透 |
| 11 | 呼吸感判断力 | 能判断读者什么时候需要喘口气 | 紧张场景后给缓冲 |
| 12 | 潜台词感知力 | 对话要有第二层意思 | 不说破，让读者品 |
| 13 | 常识检测力 | 细节经得起真实世界推敲 | 不犯低级错误 |
| 14 | 反套路判断力 | 意料之外，情理之中 | 避免读者闭眼能猜到的桥段 |
| 15 | 合规判断力 | 知道什么是安全引用 | 不踩红线 |
| 16 | 时间逻辑判断力 | 读者能感受到"过了多久" | 用事件暗示时间，不只有"第二天"标签 |
| 17 | 承上启下判断力 | 每一章开头必须让读者想起上一章结尾发生了什么 | 用一句话点明因果关系 |

## 四、章节重复检测机制（新增）

### 4.1 检测范围（10 类）

| 检测类型 | 检测内容 | 重复判定标准 |
|----------|----------|--------------|
| **完全重复语句** | 与之前章节完全相同的句子（≥15 字） | 相似度 100% |
| **高度相似语句** | 与之前章节高度相似的句子（≥80% 相似） | 仅替换个别词语 |
| **场景描写重复** | 相同场景的描写（如"食堂"、"校场"、"宿舍"） | 场景 + 细节重复 |
| **对话模式重复** | 相同对话结构（如问答模式、称呼方式） | 对话框架重复 |
| **动作描写重复** | 相同动作的描写方式（如"端起杯子喝了一口"） | 动作序列重复 |
| **神态描写重复** | 相同神态的表达（如"嘴角勾起一抹笑"） | 神态词汇重复 |
| **开篇模式重复** | 与之前章节相同的开篇方式 | 开篇结构重复 |
| **结尾模式重复** | 与之前章节相同的结尾方式 | 结尾结构重复 |
| **过渡方式重复** | 相同的时间/场景过渡方式 | 过渡词句重复 |
| **比喻修辞重复** | 相同的比喻、拟人等修辞 | 修辞表达重复 |

### 4.2 检查范围配置

| 检查模式 | 检查章节数 | 适用场景 | 处理时间 |
|----------|------------|----------|----------|
| **快速检查** | 最近 3-5 章 | 日常写作后快速自查 | 1-2 分钟 ⭐⭐⭐⭐⭐ |
| **标准检查** | 最近 10 章 | 每卷/每篇完成后 | 3-5 分钟 ⭐⭐⭐⭐ |
| **全面检查** | 最近 20 章 | 重要节点（如投稿前） | 8-12 分钟 ⭐⭐⭐ |
| **分卷检查** | 同卷内所有章节 | 多卷长篇小说 | 视卷长度而定 ⭐⭐⭐⭐ |
| **专项检查** | 用户指定章节范围 | 怀疑某几章有重复 | 视范围而定 ⭐⭐⭐⭐ |

**日常推荐**：快速检查（最近 3-5 章），平衡效率与质量。

### 4.3 重复程度分级

| 级别 | 重复比例 | 处理方式 |
|------|----------|----------|
| **严重** | ≥30% 内容重复 | 必须大幅修改 |
| **警告** | 15%-30% 内容重复 | 建议修改 |
| **注意** | 5%-15% 内容重复 | 选择性修改 |
| **安全** | <5% 内容重复 | 无需修改 |

### 4.4 常见重复场景与修改方案

| 重复场景 | 错误示例（重复） | 修改方案 |
|----------|------------------|----------|
| **食堂场景** | 每次都写"人声鼎沸、各种食物气味混杂" | 换角度：写打饭队伍、写餐具碰撞声、写某个固定人物 |
| **战斗场景** | 每次都写"刀光剑影、喊杀声震天" | 换角度：写某个兵卒的表情、写地上的影子、写战后的寂静 |
| **见面场景** | 每次都写"XX 看着 XX，点了点头" | 换角度：用动作代替、用对话代替、用环境烘托 |
| **思考场景** | 每次都写"他心里想……" | 换角度：用动作表现、用环境烘托、用对话暗示 |
| **时间过渡** | 每次都写"第二天早上" | 换角度：用光线变化、用声音、用动作暗示 |
| **情绪表达** | 每次都写"他非常愤怒" | 换角度：用动作、用环境、用对话表现 |

### 4.5 避免重复的写作技巧

1. **变换描写角度**
   - 同一场景，这次写视觉，下次写听觉/嗅觉/触觉
   - 同一动作，这次写过程，下次写结果/影响

2. **建立个人词库**
   - 为常用动作准备 3-5 种不同表达
   - 为常用神态准备 3-5 种不同描写

3. **场景差异化**
   - 相同场景（如食堂），每次突出不同特点
   - 第一次写人多，第二次写食物，第三次写某个固定人物

4. **对话个性化**
   - 不同角色有不同的说话习惯
   - 避免所有角色用相同的问答模式

5. **定期回顾**
   - 每写 5 章，快速浏览前 5 章的开篇/结尾
   - 每写 10 章，用技能检查一次重复
   - 每卷结束，进行全面检查

## 五、句式优化模块 · 禁用句式清单

### 5.1 禁用句式类（否定铺垫重复）

这类句式的问题是"先否定再肯定"，拖沓且网文味重。

#### 1. "不是……是……"结构
- **错误示例**："不是那种慢慢醒过来的疼，是胸口像被马蹄踩过。"
- **正确写法**：直接写"是"的那一半。"胸口像被马蹄踩过，他睁开眼。"

#### 2. "不是……而是……"结构  
- **错误示例**："不是想偷懒，而是真的跑不动。"
- **正确写法**：直接写结果。"真的跑不动。"

#### 3. "是被……的"结构
- **错误示例**："李元霸是被疼醒的。"
- **正确写法**：用主动句。"疼醒了李元霸。"

### 5.2 重复句式类（结构雷同）

#### 1. "一……一……"结构
- **错误示例**："一紧一松地往前挪。"
- **正确写法**：直接写状态。"队伍走走停停。"

#### 2. "像……一样""像……似的"连用
- **错误示例**："像一条被人攥在手里的绳子，攥一下动一下，松一下停一下。"
- **正确写法**：保留一个，另一个用其他方式表达。"队伍走走停停，被人攥着似的。"

### 5.3 结尾重复类

"睡觉结尾"反复出现
- **错误示例**："慢慢地睡着了。""翻了个身，把铺盖拉上来盖住肩膀。""他闭上眼睛。"
- **正确写法**：收在动作、对话、意象、环境上。"帐篷外，河水还在响。""快了。""锤面热了一下。"

### 5.4 开篇重复类

"时间交代式"开篇反复
- **错误示例**："第二天早上……""天色微亮时……"
- **正确写法**：从画面、声音、感受、动作进入。"风贴着地面走，卷起路上的土。""胸口像被马蹄踩过，他睁开眼。"

### 5.5 "复读机"模式类（句式重复）

#### 1. 连续三句同一主语 + 同一结构
- **错误示例**："李元霸站起来。李元霸拎起锤子。李元霸往外走。"
- **正确写法**：换主语、换句式、省略主语。"他站起来，拎起锤子往外走。"

#### 2. 连续对话同标签
- **错误示例**："许褚说……李元霸说……许褚说……李元霸说……"
- **正确写法**：省略标签，用动作代标签。"许褚咧嘴笑：'……'""'……'李元霸咬了一口饼子。"

#### 3. 每段开头都是"他……"
- **错误示例**："他站起来。他走过去。他蹲下来。他看着城头。"
- **正确写法**：换主语（其他角色）、换句式（用"-ing"结构、用环境开头）。

### 5.6 优化后的正确写法示例

| 错误写法 | 正确写法 |
|----------|----------|
| 不是那种慢慢醒过来的疼，是胸口像被马蹄踩过 | 胸口像被马蹄踩过，他睁开眼 |
| 一紧一松地往前挪 | 队伍走走停停 |
| 他站起来。他走过去。他蹲下来 | 站起来走过去，蹲在沟边 |
| 许褚说……李元霸说……许褚说…… | "……"许褚咧嘴笑。"……"李元霸咬了一口饼子 |
| 他闭上眼睛，慢慢地睡着了 | 帐篷外，河水还在响 |
| 第二天早上，天刚亮 | 风贴着地面走，卷起路上的土 |

### 5.7 写作时如何避免

1. **开篇**：先问自己"能不能从画面/声音/动作直接进？"能就写，不能就再想。
2. **结尾**：先问自己"能不能不睡觉？"能就换，不能就再想。
3. **句式**：写完一段，扫一眼有没有连续三句同一结构。有就改。
4. **对话**：写完对话，扫一眼有没有连续用同一个"说"字。有就换成动作或省略。
5. **描写**：写完一个场景，问自己"这个细节有用吗？"没用就删。

**提示**：这份清单可以放在大纲最后，写之前扫一眼。不用背，但写完后可以对照自查。

## 六、配角活性化 · 专项强化模块

### 6.1 核心心法

| 心法 | 说明 | 示例 |
|------|------|------|
| 三秒人生 | 配角出场时，给他三秒"与主线无关"的生活 | 食堂大妈偷吃红烧肉，嘴角有酱汁 |
| 独立台词 | 一句删了也不影响剧情，但"像他会说"的话 | "我赶着接孩子呢……"（执行任务时） |
| 配角关系网 | 配角之间有自己的关系，不都围着主角转 | A 和 B 是表兄弟但互相看不顺眼 |
| 矛盾优先级 | 配角有自己的利益，触及自己利益时会犹豫 | 平时帮主角，但涉及家人时会退缩 |
| 活性回收 | 配角用完不扔，隔几章再出现时带变化 | "上次被打的鼻梁还没好利索……" |

### 6.2 快速生成模板

每个重要配角都应具备以下要素：

```
配角名称：
一句话特征（读者记住的点）：

【三秒人生】（出场时在做什么与主线无关的事）
【独立台词】（一句"像他会说"的话）
【关系网】（和其他配角的关系）
【矛盾点】（什么情况下会和主角立场不一致）
【活性回收】（下次出现时的变化）
```

### 6.3 配角活性化检测清单（必须融入章末自检）

- 本章出现的配角，有没有至少一个"与主线无关"的动作或台词？
- 配角之间有没有互动（哪怕一句）？
- 有没有配角因为"自己的事"而暂时离开或犹豫？
- 新配角有没有一个让读者记住的特征？
- 老配角再出现时，有没有"上次之后"的变化？

## 七、输出规范

| 项目 | 规则 |
|------|------|
| 标题格式 | `# 第 X 卷 卷名` `## 第 X 章 章名` |
| 正文格式 | 段落之间空一行，纯文本，无缩进 |
| 开篇 | 直接进入场景。时间信息嵌进第二句或动作里。不用断句式交代。 |
| 标点 | 禁用破折号——，用逗号、句号或自然衔接。 |
| 字数 | 2500-3500 字灵活，以"把情节写透"为准。 |
| 禁用 | 任何表情符号。 |

## 八、写作原则

| 原则 | 说明 |
|------|------|
| 字数灵活 | 不卡死字数，写到情节透为止。以读者读着舒服为准。 |
| 节奏灵活 | 该紧则紧，该松则松。连续紧张后让读者喘口气。 |
| 逻辑灵活 | 恶搞时放飞，情感时细腻，转折时有伏笔。读者感受优先。 |
| 细节灵活 | 有烟火味，有人味，但不为细节而细节。点到为止。 |
| 读者优先 | 读者笑了、爽了、感动了，就是对的。 |
| 配角活性 | 每个人都有自己的生活，主角只是路过。 |
| 句式灵活 | 避免固定句式模式，保持语言自然多变。 |
| **避免重复** | **与之前章节保持差异化，避免读者产生"似曾相识"感。** |

## 九、章节生成自动检测清单（完整版）

每章生成后，必须自动检查以下项目：

### 基础规范
- [ ] 开篇是否直接进场景（无断句式交代）
- [ ] 标点是否禁用破折号
- [ ] 字数是否在 2500-3500 范围（或情节已写透）

### 衔接与逻辑
- [ ] 与上一章衔接是否自然（情绪、时间）
- [ ] 主角行动是否有动机
- [ ] 关键信息是否让读者和主角同步发现

### 配角活性化（专项检查）
- [ ] 本章出现的配角，有没有至少一个"与主线无关"的动作或台词？

- [ ] 新配角有没有一个让读者记住的特征？

## 十、一句话心法（完整版）

- **开篇**：直接进场景，让读者自己看见。
- **结尾**：收在情绪里，不使劲。
- **对话**：让角色自己说话，不是替作者说话。
- **细节**：点到为止，留白让读者填。
- **信息**：碎片化，和主角一起发现。
- **节奏**：该慢就慢，该快就快，读者不能累。
- **悬念**：轻吊着，不每章提。
- **人设**：主角有阅历，不会大惊小怪。
- **幽默**：来自性格，不是硬塞段子。
- **烟火气**：世界是活的，有人在收衣服，有人在逗虫子。
- **弹幕**：调味不是主菜，一章 1-2 个，让读者笑喷。
- **配角活性**：每个人都有自己的生活，主角只是路过。
- **三秒人生**：出场时给他三秒"与你无关"的时间。
- **独立台词**：那句删了也不影响剧情的话，读者记得最牢。
- **活性回收**：再见面时，他有了新发型、新烦恼、新口头禅。
- **配角关系**：他们之间有小秘密，你不知道。
- **句式灵活**：避免固定模式，打破"复读机"循环。
- **避免重复**：与之前章节保持差异，读者不应有"似曾相识"感。
- **灵活应用**：每章复盘，灵活应用规则，不盲从。

## 十一、使用流程

1. **接收输入**：获取用户提供的「题目」、「方向」、「大概」
2. **指令解析**：分析类型、风格、核心设定、本章位置
3. **读取之前章节**：读取最近 3-5 章（快速检查模式）
4. **规划创作**：应用 17 项判断力规划节奏、信息密度、情节走向
5. **生成配角**：为本章出现的每个配角应用「配角活性化模板」
6. **句式优化**：写作时应用句式优化模块，避免常见句式问题
7. **避免重复**：创作时自动规避与之前章节的重复表达
8. **写作执行**：按照输出规范和一句话心法进行写作
9. **自动检测**：完成写作后运行「章节生成自动检测清单」（含重复检测）
10. **复盘优化**：分析本章，提炼心法，记录独特表达，为下一章积累经验
