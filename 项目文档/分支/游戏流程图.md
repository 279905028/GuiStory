## 选择与回收

前三章的前情选择不提前锁定关系；正式选线发生在第三章第15天。隐藏条件单列于上图。

| 前情选择 | 后文回收 |
| --- | --- |
| 第4天见孟遥：承认紧张／先问空档 | 第三章孟遥线，对应重逢时的回应。 |
| 第10天错过约局：发语音说明／发文字并重约时间 | 第五章共通段，在新的约局中说清值班与可参加时段。 |

## 第十章后日谈分流

这是各路线到第十章后共同使用的阅读顺序，不能用婚宴替代文文自己的结局。

```mermaid
flowchart TD
    START["第十章共通开场<br/>两年后，文文仍在网吧轮班"]
    START --> CHECK{"第三章选飘线<br/>并确认交往？"}
    CHECK -->|"是"| TOGETHER["文文与飘仍是恋人<br/>与毛狼普通聚餐"]
    CHECK -->|"否：飘线朋友或其他六线"| WEDDING["飘与毛狼婚宴<br/>文文休班出席；黄球球不出席"]
    TOGETHER --> OWN["继续所选路线<br/>读取相应关系结局"]
    WEDDING --> OWN
```

后日谈和各路线结局都发生在两年后的生活中，不要求同一天。婚宴只确认飘与毛狼的关系，不影响文文在所选路线里已经作出的交往／朋友选择。
