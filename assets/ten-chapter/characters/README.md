## 文件与使用

- 每人目录的 `manifest.json` 列基准图、全部差分、实际路径、来源指纹、A01美术锚点和检查证据。复用图继续引用原文件，不复制或改写历史资源。
- 新图位于各人目录；`originals/`保留生成PNG、工具输出位置与逐张提示词。共31张生成原件，其中1张拒收版本不进入交付索引。
- `qa/`是明暗底合成与脸部细节，只供检查，不能作为透明立绘接入。画廊支持角色／新增／衣装筛选及浅深底切换。
- 九个衣装包按A01说明交基础姿态，**不是完整衣装×表情矩阵**。场景中选定衣装后不能为找表情而切回旧服装；按演出需要使用该衣装基础图或再提出明确补图需求。
- 叶岚保持大腿截幅，平底鞋在画外；周栀“外套搭椅背”由场景／演出承担。婚宴图只用于对应婚宴段，普通婚后日常仍用日常衣装。
- `cueIds`是美术锚点；`runtimeNodeIds`为空。A06复核并登记采用，E09按当前工程源映射绑定；不得把此清单视作正式游戏已更新。
