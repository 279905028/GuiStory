## 选择怎样起作用

- **沉浸选择**：本轮新增。选择不同的开口、关注点或小动作，各有即时回应，随后接同一事件；不增加好感分数、路线门槛或结局。
- **情境选择**：保留原稿已有的A／B经历与分歧，例如听完一首歌或按约离开；读完所选段落后会合。
- **入口条件**：仅共通篇记录三拍、敲回三拍两处影响黄球球路线是否开放。第14天须正式相识；相识时新增的交流选项不改变开放结果。
- **路线选择**：第三章入口决定后续阅读哪条人物路线。选择角色不等于当场确立恋爱关系。

全量编号、A／B与影响范围见[选择设计](选择设计.md)。编号服务于审阅和后续接入，编辑说明不作为角色台词。
