# E09 正式演出绑定

2026-10-23｜契约 `1.0.0`｜正文 `nightshift-20261022-r1`

本目录只拥有演出绑定。正文、选择、状态、地点和日序保持来源模块原样；A06 历史采用清单不改写。

| 文件 | 用途 |
| --- | --- |
| `prepare-bindings.cjs` | 从 A06 采用清单、节点映射、17 份正文源及 E07 逐拍请求生成正式绑定。 |
| `bindings.json` | 构建器可直接读取的角色、背景、CG、360 场景及 2577 个非门禁节点绑定。 |
| `decisions.json` | 用户对18个未点名场景的本轮确认及中性章末处理。 |
| `integration-metadata.json` | 输入指纹、应用结果、两张封面、CG 条件和变身过渡请求。 |

准备或检查：

```sh
node 任务拆分/全十章/presentation/prepare-bindings.cjs
node 任务拆分/全十章/presentation/prepare-bindings.cjs --check
```

`--check` 只比较既有产物与重新计算的字节，不写文件。所有模式先核对 A06 的35份来源指纹、138张图指纹与真实 WebP 文件签名，以及 E07 双形态来源指纹；任何漂移直接报错。改绑定规则后先重新准备，再由 E09 正式构建，不直接改生成的 `story.js`。

## 采用与逐拍决定

- 9名角色注册136张剧情图片：53张常规角色／衣装，黄球球12张主图和12张独立头像，55张背景、4张CG。另2张封面由入口使用。九个中性章末注册 `tc-bg-chapter-end: "none"`，由播放器隐藏背景图并显示深色底。
- 用户本轮确认18处未点名场景按上下文采用现有候选图，四处桌边用茶店。`location` 和正文不添地点事实。飘第七章后续概述的005—006为饭桌、007起为饭后街道，因此逐节点区分；不把整段候选街道覆盖饭局。
- 常规人物沿来源中的在场设置，并为共通、飘和朋友路线逐场补充在场镜头。电话、消息、语音、照片、尚未到场与离开后的具体节点清空实体；第一人称不强制显示文文。群聊提到的角色不因此进入现场。
- 文文、孟遥、叶岚只用A06职业适配整组，禁止旧工具包、相机、夹板回流。九个衣装用 `outfit-*` 差分键，只有基础姿态；说话者是当前衣装人物时，头像同步同衣装。小满围裙只用于实际店内工作段，新外套从第29天开始，不提前穿到第27天未拆的包裹上。孟遥第29天未写携带资料，使用普通基础图；婚宴结束后的飘恢复日常衣装。
- 背景精确 `nodeOverrides` 优先；第31天清晨关门图与孟遥朋友结局桥头暮色不外溢。所有门禁节点不写 `bg`。
- 黄球球使用 A06 的 `forms.sphere/human`，对应完整立绘与独立头像；逐拍采用 E07 的301条正文和4条控制请求。基础姿态不写不存在的 `expressions.base`，不跨形态回退。
- 4张CG只绑定A06允许的17个节点，注册 `alt`、合法节点、条件与历史事件约束。离开节点后不继承CG；显示、解锁、回顾和恢复的条件检查由播放器承担。其余6项分镜保持背景／差分／正文，不注册空CG。

## 运行时接续与验证边界

`tc_c08_huangqiuqiu_her_decision_020` 是球形淡出的过渡拍。此时仍是 `qiuForm=sphere`；必须到 `tc_c08_huangqiuqiu_human_reveal` 提交事件后才显示人形。CG仅025—027，028恢复人形立绘。不得附加恋爱条件。

运行时还须执行CG的 `allowedNodeIds`、`conditions`、`requiresEventPreviouslyExecuted` 并在图实际加载显示后解锁；婚宴排除飘交往分支、图中不出现黄球球。背景、角色及CG等比保留完整画布，下缘物件与字幕的实际叠层由E09／E10浏览器验收。

本目录完成来源核验、可复跑准备与完整候选内存编译；浏览器截图、存读档、手机、声音、真人阅读和发布结果见E09／E10交接，不由本目录替代。
