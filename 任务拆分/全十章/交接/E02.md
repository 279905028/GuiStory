## 交付

| 文件 | 用途 |
| --- | --- |
| [原构建入口](../../三章扩展/build-story.cjs) | 保留默认行为，显式分流至十章编译器 |
| [compiler.cjs](../build/compiler.cjs)、[json.cjs](../build/json.cjs) | 严格JSON、模块／版本／权限／来源／引用／演出合并校验 |
| [graph.cjs](../build/graph.cjs) | 无环、实际状态枚举、隐藏资格、事件前提、形态与结局检查 |
| [cli.cjs](../build/cli.cjs) | 只校验或隔离输出；输出目录保护、重复结果复用 |
| [完整清单模板](../build-manifest.example.json) | 17模块路径及E09绑定入口；目前是未填充模板 |
| [小型样例清单](../samples/e02/manifest.json) | 11个样例模块、31节点、16场景；未写正式common/routes目录 |
| [样例输出](../构建/sample-3d0fadf921f23ee7/build-report.json) | 隔离产物、来源索引、输入／构建器指纹、状态及事件见证 |

样例包含前三章的少量摘录、两项节奏选择、隐藏相识和七线入口，在第四章入口显式停止。样例抽象图的31节点、11选项全部可达，覆盖4种记录／回应组合，产生25个停止状态；这些数字不是正式十章覆盖率或游戏结局数。没有真实美术和完整章节。
